### VIBE CODING QOL TOOLS FOR THE GAME, INSTEAD OF PLAYING IT, IS THE REAL END GAME


Auto-generated [DIM](https://app.destinyitemmanager.com/) wishlists from community Destiny 2 spreadsheets.

## How it works

This repo runs a GitHub Actions pipeline every 8 hours that:
- Checks Bungie's Destiny 2 manifest for updates
- Downloads roll recommendations from community Google Sheets
- Generates DIM-compatible wishlist files

## For local use
Download:
 - aegis_boss-damage_spreadsheet_data_scraper.py

pip install -r requirements.txt
python pipeline_launcher.py
